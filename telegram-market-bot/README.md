# AIVerse Market Telegram Bot

ربات گزارش‌دهی فارسی بازار رمزارز و چند بازار جهانی؛ ارسال زمان‌بندی‌شده صبح و عصر.

## امکانات
- قیمت و تغییر ۲۴ ساعته BTC، ETH، SOL، XRP، BNB، ADA و TON از CoinGecko
- شاخص S&P 500، نزدک، طلا، نفت WTI و شاخص دلار از Yahoo Finance (در صورت دسترس‌بودن)
- شاخص ترس و طمع از Alternative.me
- گزارش فارسی با زمان محلی
- ثبت مقصدها در SQLite
- زمان‌بندی پیش‌فرض ۰۹:۰۰ و ۲۰:۰۰ به وقت تهران
- تحلیل متنی اختیاری با OpenAI؛ بدون کلید API هم گزارش پایه تولید می‌شود

## راه‌اندازی
1. با @BotFather یک Bot بساز و توکن را دریافت کن.
2. شناسه عددی تلگرام خودت را به‌عنوان OWNER_ID پیدا کن.
3. فایل `.env.example` را به `.env` کپی و مقادیر را تکمیل کن.
4. نصب و اجرا:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

در ویندوز فعال‌سازی محیط مجازی:
```powershell
.venv\\Scripts\\Activate.ps1
```

## ثبت گروه و کانال
- ربات را به گروه اضافه کن؛ مالک ربات دستور `/register_here` را داخل همان گروه اجرا کند.
- برای کانال، ربات را مدیر کن و شناسه عددی کانال را از گفت‌وگوی خصوصی با دستور `/addchat -100...` ثبت کن.
- ربات فقط به مقصدهایی پیام می‌دهد که مالک صریحاً ثبت کرده است.
- دستورهای مدیریتی: `/destinations`, `/removechat CHAT_ID`, `/preview`, `/sendnow`.

## استقرار دائمی
این ربات باید روی سرور/هاستی اجرا شود که پردازش Python دائمی و خروجی اینترنت را پشتیبانی کند. GitHub Pages و هاست ایستای PHP برای اجرای polling و زمان‌بند مناسب نیستند. از VPS یا سرویس کانتینری استفاده کن. Dockerfile در پروژه موجود است.

## امنیت و دقت
- فایل `.env` و توکن ربات را هرگز در GitHub قرار نده.
- در صورت افشای توکن، فوراً از BotFather آن را باطل و تعویض کن.
- قیمت‌ها و شاخص‌ها ممکن است تأخیر یا محدودیت API داشته باشند؛ داده ناموجود به‌صورت ساختگی تولید نمی‌شود.
- تحلیل، آموزشی و غیرشخصی است؛ سیگنال خرید/فروش یا تضمین سود ارائه نمی‌کند.
- قبل از استفاده عمومی، محدودیت نرخ API، خطاهای ارسال، مجوزهای ربات و پایداری هاست را پایش کن.
