# Social Growth Hub

MVP frontend for compliant social-media content planning.

## Included
- Persian RTL responsive dashboard
- Draft creation and local browser persistence
- Platform selector and draft listing
- AI assistant placeholder

## Not implemented yet
- Real AI backend
- OAuth or official social-network integrations
- Scheduled publishing
- Live analytics or monetization
- Multi-user accounts / server database

No fake followers, likes, views, or automated engagement. Drafts are stored in localStorage and are not encrypted or synchronized.
