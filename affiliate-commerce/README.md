# Partner Commerce

MVP frontend for an online storefront with affiliate/marketer workflows.

## Included
- Persian RTL responsive sample catalog
- Local affiliate-link prototype per product and partner ID
- AI assistant placeholder

## Not implemented yet
- Real inventory, cart, checkout, payment gateway, order fulfillment
- Server-side referral attribution and commission ledger
- Payouts, seller accounts, tax/legal workflows
- Real AI backend and database

All products/prices are illustrative. Links are local prototypes only; they do not track purchases or create payable commissions.
